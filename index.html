About the Project

Smart Nutrition Assistant is an educational web-based prototype. It uses HTML, CSS and JavaScript to calculate BMI, estimate calorie requirements using a BMR-based formula, and provide simple meal suggestions based on user preferences.

Note: This project is for educational/demo purposes and is not medical advice.
